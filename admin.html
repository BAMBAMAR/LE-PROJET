Configuration Publication GitHub Directe

En enregistrant votre Token GitHub (Personal Access Token), vous pouvez publier la revue de presse directement sur le site en 1 clic sans lancer aucun serveur ni terminal !

Créez un token avec permission repo ou contents:write sur github.com/settings/tokens. Ce token reste stocké uniquement dans votre navigateur (localStorage).
