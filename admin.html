       Configuration Publication GitHub Directe
      
    

    

      

        En enregistrant votre Token GitHub (Personal Access Token), vous pouvez publier la revue de presse directement sur le site en 1 clic sans lancer aucun serveur ni terminal !
      

      

        
        
      

      

        
        
        
          Créez un token avec permission repo ou contents:write sur github.com/settings/tokens. Ce token reste stocké uniquement dans votre navigateur (localStorage).
        
      

    

    

      
      
    

  






  

    

       Configuration Publication Facebook
      
    

    

      

        Connectez votre Page Facebook pour y publier directement vos visuels HD et textes en 1 clic via l'API Meta Graph. Vos identifiants restent stockés exclusivement dans votre navigateur (localStorage).
      


      

        
        
        
          Trouvez votre ID dans les Paramètres de votre Page Facebook > À propos > ID de Page.
        
      


      

        
        
        
          Jeton avec permissions pages_manage_posts et pages_read_engagement généré sur Meta Graph API Explorer.
