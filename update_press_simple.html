📝 Instructions de mise à jour

  1. Pour la presse : Téléchargez les journaux du jour en JPG/PNG
  2. Pour les actualités : Ajoutez les nouvelles actualités via le formulaire
  3. Générez les fichiers JSON correspondants
  4. Téléchargez les fichiers press.json et news.json
  5. Remplacez ces fichiers dans votre site GitHub
  6. Vérifiez que votre site affiche les nouvelles données

📂 Structure des fichiers :

press.json : Contient la liste des journaux avec images, dates et liens

news.json : Contient les actualités avec titres, dates, sources et descriptions
